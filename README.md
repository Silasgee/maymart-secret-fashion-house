# Maymart Secret

Premium clothing brand website for Maymart Secret, Lagos, Nigeria.

Upload the real brand files into the matching folders under `public/assets/`:

- `logo` — official logo files
- `hero` — strongest campaign video and fallback image
- `products` — clear clothing photos
- `gallery` — lifestyle and fashion photos
- `videos` — additional clothing and lifestyle videos

The website will be built from this GitHub repository and deployed automatically through Vercel.
